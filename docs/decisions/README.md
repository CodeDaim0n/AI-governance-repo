# Architecture decisions

These records explain intended choices; they are not evidence that a production deployment has been qualified.

| Record | Decision |
| --- | --- |
| [ADR-001](001-central-authority.md) | Central business policy remains authoritative across agent runtimes. |
| [ADR-002](002-risk-system-of-record.md) | CISO Assistant owns risk records; runtime findings are evidence. |
| [ADR-003](003-native-deployment-evidence.md) | Native integration needs an exercised product operation, not a health badge. |
| [ADR-004](004-transaction-boundary.md) | State the local transaction boundary and reconcile remote outcomes explicitly. |
